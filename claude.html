Установка и настройка окружения: Node.js 22 LTS, Claude и OmniRoute

Эта инструкция поможет быстро развернуть локальное окружение для работы с Claude через OmniRoute и использовать последнюю LTS-версию Node.js. Рассмотрим шаги по установке, настройке переменных и запуску сервера.

1. Установка Node.js 22 LTS

Для начала установите актуальную LTS-версию Node.js. В macOS это можно сделать через Homebrew:

brew install node@22

После установки проверьте, что Node.js работает:

node -v

2. Установка Claude CLI

Следующий шаг — установка Claude через официальный установочный скрипт:

curl -fsSL https://claude.ai/install.sh | bash
Совет: Перед установкой убедитесь, что у вас установлены права администратора и актуальные curl и bash.

3. Установка OmniRoute

После этого установите OmniRoute глобально с помощью npm:

npm install -g omniroute

Далее авторизуйтесь и выберите в качестве провайдера Kiro AI. Затем добавьте свой API-ключ.

4. Настройка переменных окружения

Для корректной работы систем задайте переменные окружения (например, в вашем vim ~/.zshrc или vim ~/.bashrc + source ~/.zshrc или source ~/.bashrc):

export ANTHROPIC_BASE_URL="http://localhost:20128/v1"
export ANTHROPIC_AUTH_TOKEN=sk-<your_api_token>
export ANTHROPIC_API_KEY=
export ANTHROPIC_MODEL=kr/claude-sonnet-4.5
export ANTHROPIC_SMALL_FAST_MODEL=kr/claude-sonnet-4.5
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1

Не забудьте заменить <your_api_token> на ваш реальный токен.

5. Запуск сервера OmniRoute

Чтобы активировать сервер и начать работу с Claude, выполните команду:

omniroute

После этого сервер будет доступен локально, и вы сможете отправлять запросы к API Anthropic через OmniRoute.

Заключение

Теперь всё готово к интеграции Claude в ваши проекты. Такой подход обеспечивает гибкость и возможность локальной отладки без лишнего сетевого трафика. Если появятся сложности — проверьте корректность установленных путей и переменных окружения, а также запущен ли у вас сервер OmniRoute.
