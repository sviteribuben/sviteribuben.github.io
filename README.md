# Моношинное портфолио - DA/DE/DSt Дмитрий Болдырев

Сайт-визитка в стиле The Monospace Web, вдохновленный минималистичным дизайном с использованием моноширинных шрифтов и сеточной разметки.

## Структура проекта

```
├── index.html      # Главная страница портфолио
├── style.css       # Основные стили в монопространном стиле  
├── reset.css       # CSS сброс для кроссбраузерности
├── script.js       # JavaScript для интерактивности
└── README.md       # Этот файл
```

## Развертывание на GitHub Pages

### Шаг 1: Создание репозитория
1. Создайте новый репозиторий на GitHub
2. Назовите его `username.github.io` (где username - ваше имя пользователя) для главной страницы
3. Или любое другое имя для проектной страницы

### Шаг 2: Загрузка файлов
1. Склонируйте репозиторий локально:
```bash
git clone https://github.com/username/repository-name.git
cd repository-name
```

2. Скопируйте все файлы проекта в папку репозитория

3. Закоммитьте и отправьте изменения:
```bash
git add .
git commit -m "Initial portfolio setup"
git push origin main
```

### Шаг 3: Настройка GitHub Pages
1. Перейдите в Settings репозитория
2. Найдите раздел "Pages" в боковом меню
3. В разделе "Source" выберите "Deploy from a branch"
4. Выберите ветку "main" и папку "/ (root)"
5. Нажмите "Save"

Сайт будет доступен по адресу: `https://username.github.io/repository-name`

## Особенности дизайна

### Монопространная типографика
- Использует моноширинные шрифты для всего контента
- Выровненный по сетке макет
- Минималистичный подход к дизайну

### Отзывчивый дизайн  
- Адаптируется под разные размеры экранов
- Сохраняет читаемость на мобильных устройствах
- Использует CSS Grid для компоновки

### Интерактивные элементы
- Плавная прокрутка по якорям
- Подсветка активной секции
- Анимация появления элементов при скролле
- Debug режим для разработчиков

## Настройка контента

### Персональная информация
Отредактируйте `index.html` и измените:
- Имя и должность в заголовке
- Контактную информацию
- Описание опыта работы
- Список навыков и проектов

### Стилизация
В `style.css` можно настроить:
- Цветовую схему через CSS переменные
- Размеры шрифтов и отступы
- Ширину контента и сетки
- Адаптивные брейкпоинты

### JavaScript функциональность
В `script.js` можно:
- Включить/отключить debug режим
- Настроить анимации
- Добавить дополнительную интерактивность
